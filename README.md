# GenAI.Learniverse
# 📄 Document Question Answering System

A 🤖 Generative AI based Document Question Answering System built using Hugging Face Transformers and Gradio.

---

## ✨ Features

- 📂 Upload text documents
- ❓ Ask contextual questions
- 🧠 Extract answers using NLP
- 🎯 Transformer-based Question Answering
- 🌐 Interactive Gradio Interface

---

## 🛠️ Tech Stack

- 🐍 Python
- 🤗 Hugging Face Transformers
- 🎨 Gradio
- 🧠 NLP
- ⚡ Deep Learning

---

## 🤖 Model Used

- `deepset/roberta-base-squad2`

---

## 🚀 Installation

Clone the repository:

```bash
git clone <your-repository-link>
cd document-qa-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

---

## ⚙️ How It Works

1. 📤 Upload a `.txt` document  
2. ❓ Ask a question related to the document  
3. 🧠 The transformer model extracts the most relevant answer from the document context  

---

## 💡 Example Questions

- What is Artificial Intelligence?
- Who founded the company?
- When was the event held?
